
# ⚒️ How to start
1. 📥 Download Repository
```sh
git clone --recursive https://github.com/Secure-Your-Soul/SecureOS.git
```
2. 📦 Install Dependensies
```
make i 
```
3. 🔨 Build Project
```
make
```
4. 🚀 Get SecureOS.iso
```sh
cd output && ls
```
## 🤝 How to Contribute

I am building **SecureOS** from scratch, and I would love your help! Whether you are an experienced kernel developer or just starting your journey with OS development, there is a place for you here.

### 🚀 How can you help?
- **🛡️ [Report a Security Vulnerability](https://github.com/Secure-Your-Soul/SecureOS/issues/new?assignees=&labels=security&template=security.md&title=%5BSECURITY%5D%3A+)** – Found a security flaw? Please review this first.

- **🐛 [Report a Bug](https://github.com/Secure-Your-Soul/SecureOS/issues/new?assignees=&labels=bug&template=bug_report.md&title=%5BBUG%5D%3A+)** – Something not working as expected? Let me know!
- **💡 [Request a Feature](https://github.com/Secure-Your-Soul/SecureOS/issues/new?assignees=&labels=enhancement&template=feature_request.md&title=%5BFEATURE%5D%3A+)** – Have a cool idea? Share it with me!
- **❓ [Ask a Question](https://github.com/Secure-Your-Soul/SecureOS/issues/new?assignees=&labels=question&template=question.md&title=%5BQUESTION%5D%3A+)** – Need help or have a question about SecureOS?
- **🧹 [Code Cleanup & Chore](https://github.com/Secure-Your-Soul/SecureOS/issues/new?assignees=&labels=chore&template=cleanup.md&title=%5BCHORE%5D%3A+)** – Spotted a typo, want to do some housekeeping, or clean up code formatting?
- **📖 [Improve Documentation](https://github.com/Secure-Your-Soul/SecureOS/edit/main/README.md)** – Edit the README directly to explain something better.

### 🛠️ Getting Started (The Workflow)

1. **Fork** the repository 🍴
2. **Create a feature branch** (`git checkout -b feature/amazing-feature`) 🌿
3. **Commit** your changes (`git commit -m 'Add some amazing feature'`) 💾
4. **Push** to the branch (`git push origin feature/amazing-feature`) 🚀
5. **Open a Pull Request** 🔀
